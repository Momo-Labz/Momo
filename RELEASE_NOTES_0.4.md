# BAR BOY 0.4 — compact command center

BAR BOY now opens as a short, models-only menu popup and expands into a wider three-tab workspace when you need context.

## New

- Horizontal Home, Agents, and Tools views instead of one tall dashboard.
- Official installed-app marks for Codex, Claude, and Cursor plus recognizable Gemini and Grok marks, all rendered in monochrome.
- A compact model strip with one clear Expand action.
- Momo Labz pixel styling and a restrained one-shot mascot entrance.
- Matching Home, Agents, and Tools navigation in MOMO RELAY for iPhone.
- A checked-in `DESIGN.md` contract for spacing, color, typography, components, and motion.
- Provider-specific streaming adapters for Claude, Codex, and Cursor with main/subagent role, token, model, attention, and capability evidence where each schema supports it.
- Installed MCP, plugin, marketplace, and skill inventory with a separate, evidence-based `USED` state.
- Enabled-provider isolation: switching a provider off also stops its disk, process, and configuration scans.
- A versioned relay JSON contract shared by macOS and iOS.
- Keychain-separated iPhone credentials and Bearer-authenticated status polling.
- Hardened local Desk Display pairing, Host checks, privacy redaction, browser security headers, and automatic port fallback.
- Sanitized adapter/inventory fixtures, env-gated snapshots, and aggregate-only real-data smoke checks.
- Printable 100 × 72 × 28 mm Agent Desk body, vented back, and stand STL prototypes for a 480 × 320 screen.

## Product truth

- Consumer subscription quota APIs remain inconsistent. A dash means BAR BOY does not have a verified number.
- Provider authorization is still a capability map; no credentials are collected in this build.
- Installed capability presence does not imply that a session used it; only recorded provenance receives a `USED` mark.
- Claude, Codex, and Cursor have dedicated schema adapters. Gemini and Grok remain conservative generic discovery until representative fixtures are available.
- The macOS DMG is an ad-hoc-signed development build. Public distribution still requires Momo Labz Developer ID signing and notarization.
- iPhone installation still requires the Momo Labz Apple Developer Team or TestFlight distribution.
